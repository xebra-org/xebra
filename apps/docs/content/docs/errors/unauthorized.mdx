HTTP **401**. `type`: `https://docs.xebra.exchange/errors/unauthorized`

## What it means

The API currently does not send this code. It reserves `unauthorized` for a future API-key check, but no
authentication is enabled today.

## What to do

The API needs no key today. If authentication is added later, check the `Authorization: Bearer ...`
header and the key's status.

<Callout>API keys are not issued yet. See the [changelog](/docs/changelog).</Callout>

Every error has this shape. See [Errors](/docs/errors) for how to handle them.
