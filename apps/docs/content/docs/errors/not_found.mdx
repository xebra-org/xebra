HTTP **404**. `type`: `https://docs.xebra.exchange/errors/not_found`

## What it means

Nothing answers at this path. On `api.xebra.exchange`, everything lives under `/v1`.

## What to do

Check the path against the [API reference](/docs/api).

Before waiting, confirm the burn succeeded on the source chain (check the transaction on the source chain's [block explorer](https://stellar.expert/explorer/public)). A hash Circle has never seen stays `pending`; it is not a 404.

## Example

```json
{
  "type": "https://docs.xebra.exchange/errors/not_found",
  "title": "Not found",
  "status": 404,
  "detail": "The API has no such endpoint. See https://docs.xebra.exchange/api.",
  "code": "not_found"
}
```

Every error has this shape. See [Errors](/docs/errors) for how to handle them.
