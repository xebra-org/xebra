## Check one yourself

Ask the API for any of them. It reads Circle's record and the destination chain; nothing here is
stored by us.

```sh
curl https://api.xebra.exchange/v1/transfers/stellar/a09a9d8340e92ff670598247d63261a3964531b0dc48693e1dc4733f5707e60e
curl https://api.xebra.exchange/v1/transfers/sui/F7qiEMaT7q7pbfQ2H44SeV4URQQVfNpffmpt3J5yH8pD
```

Each answers `"state": "delivered"` with the mint transaction in `deliveryTx`. The same lookup is
`xebra.getTransfer(chain, tx)` in the [SDK](/docs/sdk), and [Track a transfer](/docs/guides/track-a-transfer)
covers the states.

You can also skip us entirely: Circle's own API reports every CCTP burn by its transaction hash.

```sh
curl "https://iris-api.circle.com/v2/messages/8?transactionHash=F7qiEMaT7q7pbfQ2H44SeV4URQQVfNpffmpt3J5yH8pD"
```

`8` is Sui's CCTP domain (Stellar is `27`). The answer shows `"status": "complete"` and, for a
forwarded transfer, `"forwardState": "COMPLETE"` with the mint's hash.
